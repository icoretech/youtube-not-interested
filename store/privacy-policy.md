# Not Interested Right-Click for YouTube: Privacy Policy

_Last updated: 19 November 2026_

Not Interested Right-Click for YouTube ("Not Interested") is a browser extension published by iCoreTech (icorete.ch). When you right-click a video thumbnail on youtube.com, it opens that video's menu and chooses "Not interested" for you, as if you had clicked it yourself.

## What Not Interested does with data

- **It works only with the page you are looking at.** On youtube.com, it reads the video cards and menus that YouTube has already displayed, to find the thumbnail you right-clicked and the "Not interested" entry in its menu.
- **It sends nothing anywhere.** Not Interested makes no network requests of its own. It has no servers, no accounts, no analytics, no telemetry and no tracking. Marking a video "Not interested" is done by YouTube's own menu, exactly as when you click it yourself.
- **It stores nothing.** Not Interested does not use browser storage, cookies or any other persistent storage.
- **It sells or shares nothing**, because it collects nothing.

## Permissions

Not Interested declares no browser permissions. It runs only on `https://www.youtube.com/*`, which it needs in order to respond to right-clicks on YouTube's pages.

## Changes

If a future version changes any of the above, for example by adding optional features that save settings, this policy will be updated before that version is released, and the change will be described here.
